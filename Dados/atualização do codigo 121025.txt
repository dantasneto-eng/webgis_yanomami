Conectar o vs codigo direto no github:
1.Crie o repositório no GitHub:
Acesse github.com
Clique em "New repository"
Dê um nome, escolha "Public" ou "Private", e clique em "Create repository"

2. No terminal do VS Code, rode estes comandos:

git init
git add .
git commit -m "Primeiro commit do WebGIS"
git remote add origin https://https://github.com/MARCIOCOSTAPI/SIGWEB.git
git branch -M main
git push -u origin main
